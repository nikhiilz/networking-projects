Base IP: 192.168.1.0/24

It is subnetted into /26 networks to support each department separately

Dept 1 = Admin = vlan 10
Dept 2 = Finance = vlan 20
Dept 3 = Customer Service = vlan 30

Admin IP addressing
Network Address: 192.168.1.0/26
Default Gateway: 192.168.1.1/26 reserved for inter-vlan routing
First Usable IP: 192.168.1.2/26
Last Usable IP: 192.168.1.62/26
Broadcast IP: 192.168.1.63/26

Finance IP addressing
Network Address: 192.168.1.64/26
Default Gateway: 192.168.1.65/26
First Usable IP: 192.168.1.66/26
Last Usable IP: 192.168.1.126/26
Broadcast IP: 192.168.1.127/26

Customer Service IP addressing
Network Address: 192.168.1.128/26
Default Gateway: 192.168.1.129/26
First Usable IP: 192.168.1.130/26
Last Usable IP: 192.168.1.190/26
Broadcast IP: 192.168.1.192/26
